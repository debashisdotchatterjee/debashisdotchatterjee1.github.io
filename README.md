# Debashis Chatterjee — Academic Website

A responsive, dependency-free academic website built from the supplied CV (dated 10 June 2026).

## Pages
- `index.html` — academic landing page
- `publications.html` — searchable publications and selected active work
- `teaching.html` — teaching, mentoring, invited lectures and service
- `cv.html` — concise web CV
- `Debashis_Chatterjee_CV.pdf` — source CV

## Design decisions
- No personal phone number, date of birth, permanent home address, category, or other unnecessary personal details are exposed.
- Official institutional email is used for contact.
- The site is static and has no external JavaScript or font dependencies.
- A dark/light theme toggle and publication filtering are included.

## Publishing
Upload the whole folder to any static-site host, or import/publish the contents using a compatible site builder. Keep all files together so the CV and shared assets resolve correctly.
